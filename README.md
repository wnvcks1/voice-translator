# 동시통역 (테스트판 v0.1)

한국어 ⇄ 중국어(영·일·스페인어 선택 가능) 대면 통역 웹앱. 폰 하나를 테이블에 두고 양쪽이 번갈아 말하면
언어를 자동 판별해 원문을 받아적고, 번역해서 화면에 띄우고 소리로 읽어 줌. 말한 사람이 남자면 남자 음성, 여자면 여자 음성.

- 받아쓰기·언어 판별·번역: Gemini API 무료 등급 (음성을 직접 넣어 한 번에 처리, 스트리밍)
- 남/여 판별: 폰 안에서 음높이(F0) 계산 — 남 ≤160Hz, 여 ≥180Hz, 사이는 Gemini 판정으로 보완
- 음성 재생: 기본은 폰 내장 TTS(무료·즉시). 설정에서 Gemini AI 음성 켜면 더 자연스러운 남/여 음성
- 키는 폰 브라우저 localStorage 에만 저장. 서버 없음, 빌드 없음

테스트: `npm test` (단위 28건), `npm run e2e` (가짜 마이크 + API 흉내로 전체 흐름, playwright 필요)
