# 동시통역 (테스트판 v0.6)

한국어 ⇄ 중국어(영·일·스페인어 선택 가능) 대면 통역 웹앱. 폰 하나를 테이블에 두고 양쪽이 번갈아 말하면
언어를 자동 판별해 원문을 받아적고, 번역해서 화면에 띄우고 소리로 읽어 줌.
한국어로 말한 건 왼쪽, 상대 언어로 말한 건 오른쪽 카드.

통화 화면: 가운데 버튼으로 통화 시작 → 빨간 버튼으로 끊기. 통화 시간·음소거 버튼.
음량: 화면 슬라이더(기본 0.6)가 모든 번역 소리에 적용. 통화 모드에선 폰 측면 버튼이 번역 소리를 못 줄이는 기기가 있음.
번역 검수(실시간, 기본 켬): 말이 끝나면 원문을 Flash-Lite 글 번역으로 한 번 더 확인해 뜻이 틀렸으면 카드를 고치고 '정정'을 AI 음성으로 읽음.

마이크(통화 모드): 에코 제거·잡음 제거·자동 음량·목소리 분리(지원 기기) → 85Hz 아래 웅웅거림 제거 →
오디오 전용 스레드 수집(화면이 바빠도 소리 안 끊김) → 앨리어싱 없는 16kHz 변환(127탭 FIR). 감도 3단계.

누가 말했나(왼쪽/오른쪽): ① 받아적은 글자 종류(한글/한자) ② Gemini 판정 ③ 목소리.
목소리는 대화 중 글자로 확실히 갈린 말에서 양쪽 음높이+음색(MFCC)을 배워, '네'·'OK'·숫자처럼 글자로 안 갈리는 말에만 씀.
두 사람 음높이가 3반음 이상 다를 때만(대략 남녀) 판정. 혼자 두 언어로 말하거나 같은 성별 둘이면 판정 안 함.
목소리 판정은 Gemini 에 알려 주지 않음 — 알려 주면 그 언어로 들으려는 편향이 생김.

전화처럼 계속 들음: 번역은 백그라운드에서 돌고, 번역 음성이 나오는 동안에도 마이크는 안 멈춤.
스피커 소리가 다시 마이크로 들어와 또 번역되는 것(에코)은 최근 20초 내보낸 말과 글자 비교로 걸러냄.

두 가지 모드
- 실시간 모드(기본): Gemini Live Translate 세션 2개(→상대 언어, →한국어)에 마이크 소리를 계속 흘려보내
  말하는 도중에 번역 음성이 나옴. 같은 언어 되풀이 소리는 글자 종류로 걸러냄. 연결 실패하면 문장 모드로 자동 전환.
- 문장 모드: 말이 끝나면(0.7초 침묵) 그 한마디를 Gemini 에 보내 언어 판별·받아쓰기·번역을 한 번에 받음.
  번역 모델은 Flash-Lite 우선(무료 일일 한도가 큼), 한도 초과(429) 나면 다음 모델로 자동 전환.
  폰 음성으로 읽고, 폰 음성이 실패하면 Gemini AI 음성으로 대체.

남/여 판별: 폰 안에서 음높이(F0) 계산 — 남 ≤160Hz, 여 ≥180Hz. 애매하면 같은 쪽 누적 음높이, 그다음 Gemini 추측.
번역 목소리 성별: 실시간 모드는 번역 방향마다(→상대 언어 = 한국어로 말한 사람, →한국어 = 상대 언어로 말한 사람)
말한 사람 음높이에 맞춰 남/여 목소리로 세션을 다시 열고 그 말을 처음부터 다시 보냄(쪽마다 처음 한 번, ~1초).
쪽마다 성별을 기억해 다음 통화는 처음부터 맞는 목소리. 모델이 목소리 지정을 거부하면 번역 글을 앱 음성으로 성별 맞춰 읽음.
키는 폰 브라우저 localStorage 에만 저장. 서버 없음, 빌드 없음.
